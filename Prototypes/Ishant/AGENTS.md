# Titan design-system tasks

For requests to enrich, apply, or build with the Titan design system, read
`../../design-system/AGENTS.md` and `../../design-system/USAGE.md` relative to this
folder. The shared system supports new screens and user-requested alignment of
existing screens across the workspace. Reference screens are evidence, not limits.

Run instructions: `commands/start-studio.md`.

If the task adds or changes a shared component, also follow the required
[component checklist](../../design-system/COMPONENT-CHECKLIST.md) before implementation
and handoff. The DS folder being gitignored does not prevent reading these files.
