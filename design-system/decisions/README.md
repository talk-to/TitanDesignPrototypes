# Decisions

Record evidence, scope, approved exceptions and verification here.

Decision files describe the pass in which they were written. Statements such as
“catalog empty”, “out of scope” or “browser review pending” apply to that pass;
they do not automatically describe the current system or prohibit later authorized work.
Keep historical evidence rather than rewriting old results as newly verified.

For current registrations, inspect `../registry.json` and its referenced source files.
Use `../USAGE.md` for current usage and `../BRIEF.md` for current direction. Consult
later decisions on the same topic for explicit corrections and superseding choices.
Registration alone does not close a verification gap.
