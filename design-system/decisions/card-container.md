# Card construct

Card is a basic layout construct, not a registered component. Removed its catalog
entry and specimen. Retained --titan-card-inset → --titan-space-16 in Foundations
and the optional .titan-card CSS utility for applying the default container styling.
No nested-card requirement, section structure or interaction contract is implied.
Register meaningful reusable compositions only when observed or explicitly requested.

Attachment validation and existing component tests pass.
