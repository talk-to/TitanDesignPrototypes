# Icon registration

Registered 45 named SVG assets from the DS-specific TitanEmailShell: observed email actions, composer controls, and app-switcher artwork. `icons/catalog.json` records each original source path and stable DS asset path. Files are byte-preserving copies; existing shell/component imports remain unchanged. This registers reusable assets without claiming migration of their existing consumers.

Interface, Formatting and Apps are browsing categories, not new component families. Background illustrations, avatars, separators and layout thumbnails are excluded. This is a curated initial inventory, not a claim that every anonymous source SVG is classified. Preserve intrinsic proportions and source colors. The Titan Labs specimen applies the source's 180-degree rotation. White-only artwork receives a dark display backing, not recoloring.

The searchable grid copies concise DS-change context, name, ID and shared asset path. Icon assets own no hover/click behavior; containing controls retain those contracts. Gallery hover/copy belongs only to the catalog UI. Parent controls own slot size and spacing; the 24/32px gallery sizes do not establish new DS sizing tokens.

Validation checks manifest identity, source existence and byte preservation. Interactive browser visual/clipboard checks were unavailable in this session.

Gallery sizing correction: explicit image dimensions follow each source viewBox ratio, including exports using preserveAspectRatio=none. All samples fit within 24px; intrinsic artwork whitespace remains preserved. The misleading source filename figma-ic-link.svg is registered as more-vertical after inspecting its paths and source button title.
