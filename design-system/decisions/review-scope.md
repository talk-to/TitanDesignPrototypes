# Proportionate review scope

The user requested simpler checks. COMPONENT-CHECKLIST.md now selects reviews by
change type and impact. It supersedes blanket full-component audits for every edit
in the installed studio workflow for this Titan attachment only. Shared studio
files and contracts are unchanged.

Full reviews remain for new components and affected structural/API changes. Small
visual, spacing, preview and screen changes get targeted checks. Shared token edits
require consumer discovery; visual changes affecting accessibility also get the
relevant accessibility checks. Metadata is updated only when made stale. Routine
edits do not require new audit documents. Missing browser review remains explicit.

AGENTS.md and USAGE.md point to this policy. History is read when relevant rather
than on every task. Verification: reviewed the changed guidance for conflicting
blanket requirements and checked local Markdown links. No runtime behavior changed.

## Spacing priority clarified

The user identifies spacing as the most frequent problem in generated prototypes.
Spacing inspection and accurate internal component mappings therefore remain core.
New/rearranged screens get a visual spacing review covering parent-owned relationships
as well as component integration. Unsupported inspector coverage uses available
browser geometry/computed styles, with limitations reported; no new inspector
capability is claimed. Unrelated re-audits and routine audit paperwork remain omitted.
This clarification changes guidance only, not inspector code or existing mappings.
