# Text style relationship draft

The user requested a trial view connecting primitives on the left to text styles
on the right, with faint connections, hover highlighting and click selection.
Heading, Body, Label and Caption are app-owned draft recipes in the registry.
Only Body currently assigns the observed 20px line-height token. Other line heights
remain unassigned; their preview uses normal line height. No screen adopts these
recipes yet. They are proposals for review, not established semantic standards.

Heading now has draft Large (24px), Medium (15px), and Small (14px) styles,
all semibold. These reuse the observed primitive scale; no new sizes are invented.
The original heading aliases are retained for compatibility.

Correction: the user rejected speculative heading variants. Removed Medium/Small
and restored the single observed heading. New heading types require screen evidence.
