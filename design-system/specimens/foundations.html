03 / Review notes

Keep the differences visible

Two reading values already exist

The active reading surfaces use #fbfbfb. The earlier --reading-pane-bg declaration is #f9f9fa. Both are retained; the new reading role follows the actual surface declarations.

Active reading surface
--titan-surface-reading · #fbfbfb
Legacy declared control
--reading-pane-bg · #f9f9fa

116 declarations adopted across 62 selectors

Selected static CSS now consumes these foundations. Every substituted value resolves to the original literal. The shell’s JavaScript, inline styles, SVGs, layout and interaction rules are preserved. This is partial adoption, not a whole-app token conversion.

Before approving visual changes

  • Review inbox, reading pane, composer and settings at 1440×900 and 1280×800; inspect overflow at 768×900.
  • Review #888 metadata on light backgrounds for contrast. Preserve it for this pass; no accessibility approval is claimed.
  • Keep wide-view sender size, timestamp size, varied hover backgrounds and local line heights as explicit exceptions.
  • Spacing and elevation have dedicated review pages. Elevation roles preserve observed shadows; focus effects, themes and component state contracts remain separate work.
