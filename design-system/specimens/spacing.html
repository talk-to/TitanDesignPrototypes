02 / Ownership

Same value, different relationship

The reading pane owns its outer inset. A message owns its inner padding. Changing one role should not silently change the other. These tokens describe existing source relationships; no reusable component has been extracted.

Raw distances do not define components

Toolbar gaps, settings padding and the existing 8px message margins use primitive values directly. Their selectors still own those declarations. Existing nested margins remain in place; no new parent gap is added.

03 / Exceptions

Preserve the layout mechanics

Wide-view rows

Keep 0 / 16 / 0 / 21px padding, 44px line-height alignment, and the 160px action reserve. Row density and action placement are unchanged.

Collapsed thread stacks

The −50px overlap and 60px card height work together. They stay local; the spacing scale does not control stack geometry.

Composer vs. inline reply

Send bars use different 16px / 24px horizontal insets, with source-order and inline overrides. This pass leaves that cascade intact.

Optical and control adjustments

1, 2, 3, 5, 6, 10, 11 and 14px values remain where used. No rounding, new density mode or breakpoint has been introduced.

Review checkpoint
